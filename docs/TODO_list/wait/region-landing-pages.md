# 경주·포항 지역 안내 페이지에 실제 방문 범위 더하기

2026-10-22 지역 안내 페이지(`/area/gyeongju`, `/area/pohang`)를 만들었다. 지금 지역마다 다른 내용은
관할 건강보험공단 지사 정보뿐이고, 방문 범위는 "경주시(포항시) 가정을 방문하고 있습니다"로만 적었다.
원칙은 [`docs/specs/area-pages.md`](../../specs/area-pages.md).

2026-09-15 네이버 검색 결과(사용자 화면 확인): "안강 노인복지센터"는 1순위,
"경주 노인복지센터"·"포항 노인복지센터"는 노출되지 않았다. 네이버 플레이스 등록명은
`섬김노인복지센터`, 주소는 경주시 안강읍 화전중앙길 53이다.

## 막힌 이유

**실제 방문하는 곳과 이용 현황은 센터만 안다.** 공단 지사 정보만으로는 두 페이지의 차이가 얇다.

## 트리거

센터가 아래 질문 1번에 답한다. 2·3번은 없어도 넣을 수 있지만 페이지가 얇게 남는다.

## 착수 시 정할 것

### 센터에 물을 것

1. 경주는 안강읍 말고 어느 읍·면·동까지 방문하시나요? 포항은 어디어디 가시나요?
   실제로 가고 계신 곳만 알려주세요.
2. 지금 경주 시내나 포항에서 서비스를 받는 어르신, 활동하는 요양보호사가 계신가요?
   대략적인 인원을 홈페이지에 적어도 될까요?
3. 그 지역 어르신 사례나 보호자 후기 중에 이름을 빼고 소개해도 되는 것이 있을까요?

### 착수 때 개발 쪽에서 조사할 것

- 센터에서 각 지역까지 차량 이동 시간

### 선택지

- **기대치** — 네이버 플레이스(지도) 영역은 주소와의 거리를 반영하므로, "포항 노인복지센터"
  플레이스 상단은 페이지를 만들어도 바뀌지 않는다. 페이지가 노릴 곳은 웹사이트 영역이다.
- **측정** — 네이버는 검색 데이터 API가 없어 순위는 검색 화면으로 본다. 유입은 GA4의
  naver 소스로 본다.
