# 경주·포항 지역 안내 페이지

"경주 노인복지센터"·"포항 노인복지센터"로 검색했을 때 걸릴 페이지가 사이트에 없다.

2026-09-15 네이버 검색 결과(사용자 화면 확인): "안강 노인복지센터"는 1순위,
"경주 노인복지센터"·"포항 노인복지센터"는 노출되지 않았다. 네이버 플레이스 등록명은
`섬김노인복지센터`, 주소는 경주시 안강읍 화전중앙길 53이다.

사이트에서 지역은 "경주·안강·영천·포항" 같은 나열로 나오고(홈 히어로, 방문요양, 인사말 등),
한 지역을 주제로 한 페이지는 없다.

## 막힌 이유

**지역마다 다른 실제 내용이 없다.** 지역명만 바꿔 찍은 페이지는 네이버·구글 모두
저품질로 판단해 사이트 평가를 깎을 수 있어, 내용 없이 만들면 안 만드는 것보다 나쁘다.
그 내용(실제 방문 지역, 이용 현황)은 센터만 안다.

## 트리거

센터가 아래 질문 1번에 답한다. 2~4번은 없어도 착수할 수 있지만 페이지가 얇아진다.

## 착수 시 정할 것

### 센터에 물을 것

1. 경주는 안강읍 말고 어느 읍·면·동까지 방문하시나요? 포항은 어디어디 가시나요?
   실제로 가고 계신 곳만 알려주세요.
2. 지금 경주 시내나 포항에서 서비스를 받는 어르신, 활동하는 요양보호사가 계신가요?
   대략적인 인원을 홈페이지에 적어도 될까요?
3. 목욕차가 경주 시내와 포항까지 가나요?
4. 그 지역 어르신 사례나 보호자 후기 중에 이름을 빼고 소개해도 되는 것이 있을까요?
5. 영천도 서비스 지역으로 소개하고 있는데, 영천 안내 페이지도 만들까요?

### 착수 때 개발 쪽에서 조사할 것

- 지역별 국민건강보험공단 담당 지사(등급 신청 창구)
- 센터에서 각 지역까지 차량 이동 시간

### 선택지

- **페이지 형태** — ① 지역별 독립 페이지(예: `/area/gyeongju`, `/area/pohang`)
  ② 방문요양 페이지 안의 지역 섹션. ①은 검색어 하나에 맞는 페이지 하나가 된다.
  ②는 한 페이지에 지역이 섞여 어느 검색어에도 약하다.
- **메뉴 위치** — 상단 메뉴에 칸을 늘리지 않아도 된다. 센터소개 아래 "서비스 지역" 한 칸, 또는
  방문요양 페이지·푸터의 링크 중 하나. 어느 쪽이든 링크가 서버 HTML에 실려야 검색엔진이 찾는다
  (하위 메뉴 링크가 빠져 색인되지 않던 `37e23e4`와 같은 원인).
- **안강 페이지** — 홈이 이미 "안강 노인복지센터" 1순위라, 안강 전용 페이지를 만들면
  같은 검색어를 두고 홈과 겹친다. 만들지 않는 쪽이 기본.
- **기대치** — 네이버 플레이스(지도) 영역은 주소와의 거리를 반영하므로, "포항 노인복지센터"
  플레이스 상단은 페이지를 만들어도 바뀌지 않는다. 페이지가 노릴 곳은 웹사이트 영역이다.
- **측정** — 네이버는 검색 데이터 API가 없어 순위는 검색 화면으로 본다. 유입은 GA4의
  naver 소스로 본다.
