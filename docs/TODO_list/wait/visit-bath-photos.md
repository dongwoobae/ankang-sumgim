# 방문목욕 서비스 페이지

센터 간판과 네이버 플레이스 사진에는 "방문요양 방문목욕"이 적혀 있는데, 사이트에는 방문목욕을
서비스로 설명하는 페이지가 없다. 서비스 메뉴(`components/layout/Header.tsx`)는
노인장기요양보험이란·방문요양서비스·가족요양·등급신청·인지활동서비스이고, 목욕차는
"목욕차 2대" 수치로만 나온다(홈 통계, 방문요양 페이지 하이라이트).

## 막힌 이유

**목욕차 사진과 운영 방식은 센터만 안다.** 차량 안에서 씻는지, 몇 분이 가는지 같은 운영 방식을
추측으로 쓰면 실제 서비스와 달라진다.

## 트리거

센터에서 목욕차 사진과 아래 질문 1~4번의 답을 받는다.

## 착수 시 정할 것

### 센터에서 받아올 것

사진

- 목욕차 외관 (센터 이름이 보이게)
- 차량 안 욕조·온수 설비
- 목욕 준비·진행 모습 — 어르신 얼굴이 나오지 않거나 게시 동의를 받은 사진만

질문

1. 목욕은 차량 안에서 하나요, 댁 안 욕실에서 하나요? 둘 다 하나요?
2. 한 번 방문에 요양보호사 몇 분이 가고, 시간은 얼마나 걸리나요?
3. 누워 계시거나 휠체어를 타는 어르신도 이용할 수 있나요?
4. 방문요양 없이 방문목욕만 따로 신청할 수 있나요?
5. 목욕차가 가는 지역은 어디까지인가요?
   ([region-landing-pages.md](region-landing-pages.md) 3번과 같은 질문이라 한 번에 묻는다)
6. 사이트에 "타 센터 대비 2배 보유", "지역 최다 보유"라고 적혀 있는데, 비교한 근거가 있나요?
   비교 표현은 근거를 요구받을 수 있어, 근거가 없으면 "목욕차 2대 보유"로 바꾸는 게 안전하다.

### 착수 때 개발 쪽에서 조사할 것

- 장기요양 방문목욕 급여 기준과 수가(차량 이용 여부에 따른 차이), 본인부담률
- 본인부담금 계산기(`/calculator`)에 방문목욕을 넣을지 — 계산기 기준값 구조부터 확인한다

### 선택지

- **페이지 위치** — 서비스 메뉴의 방문요양서비스 옆에 "방문목욕"을 둔다(예: `/services/visit-bath`).
  실제로 제공하는 서비스라 지역 페이지와 달리 메뉴 칸을 두는 게 자연스럽다.
- **방문요양 페이지의 목욕차 하이라이트** — 그대로 두고 방문목욕 페이지로 링크를 걸지, 옮길지.
- **검색 제목** — "방문목욕 | 섬김노인복지센터"에 지역(경주·안강)을 붙일지.
