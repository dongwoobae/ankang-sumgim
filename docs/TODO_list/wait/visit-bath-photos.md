# 방문목욕 페이지의 두 번째 목욕차·내부 사진

방문목욕 페이지(`/services/visit-bath`)의 사진은 2026-10-01에 받은 묶음에서 골랐다. 그 묶음은 모두
같은 차(번호판이 같다)이고 내부는 어르신을 모시는 장면 너머로만 보인다. 사이트는 "목욕차 2대"라고
쓰는데 사진으로는 한 대만 보인다.

## 막힌 이유

**사진이 아직 오지 않았다.** 2026-10-06 센터가 "목욕차 각기 다른 차로 사진 찍고 내부 사진도 찍어
보낼게"라고 했다. 두 대를 한 화면에 담는 건 어렵다고 했다.

## 트리거

센터에서 두 번째 차 외관이나 내부 설비 사진이 온다.

## 착수 시 정할 것

- 블러·업로드는 [`docs/specs/visit-bath.md`](../../specs/visit-bath.md) "사진"을 따른다.
- 두 번째 차 사진은 페이지 `photos` 배열에 더한다. 내부 사진이 여러 장이면 욕조·온수 설비를 따로
  보여 주는 섹션을 둘지 정한다.
