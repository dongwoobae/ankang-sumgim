# 사이트의 서비스 지역에 영천이 남아 있다

홈 히어로·통계, 방문요양·인사말 페이지, 메타 설명, 구조화 데이터(`areaServed`)가 서비스 지역을
"경주·안강·영천·포항"으로 적는다. 위치는 `rg -n 영천 app components lib`로 찾는다.

2026-10-06 센터 회신으로 목욕차는 영천에 가지 않는다(이용자가 없어 기름값·이동 효율이 맞지 않음).
방문요양도 영천에 가지 않는지는 묻지 않았다.

## 막힌 이유

**방문요양의 영천 방문 여부를 센터만 안다.** 방문요양을 하고 있다면 지금 문구가 맞고,
하지 않는다면 서비스하지 않는 지역을 광고하는 셈이다.

## 트리거

센터가 아래 질문에 답한다.

## 착수 시 정할 것

### 센터에 물을 것

1. 방문요양도 지금 영천에는 가지 않으시나요? 사이트에 영천이 서비스 지역으로 적혀 있어서,
   안 가시면 빼려고 합니다.

### 선택지

- 방문요양은 가고 목욕차만 안 간다면 문구는 그대로 두고, 방문목욕 운행 지역만 따로 적는 지금 상태를 유지한다.
- 둘 다 안 간다면 위 `rg` 결과를 모두 고친다. `lib/seo.ts`의 `areaServed`와 루트 메타 키워드도 포함한다.
