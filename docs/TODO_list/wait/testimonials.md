# 사이트에 올릴 후기·어르신 사례

## 막힌 이유

**후기와 사례는 센터에만 있다.** 2026-10-22 센터에 "이름은 빼고 올릴 만한 후기나 사연, 어르신 사례"를
부탁했고 "찾아볼게"라는 답을 받았다.

## 트리거

센터에서 후기나 사례가 온다.

## 착수 시 정할 것

- 둘 곳: 특정 지역 어르신의 사례라면 그 지역 안내 페이지에 둔다. 공단 지사 말고 지역마다 다른 내용이 되기 때문이다
  ([`docs/specs/area-pages.md`](../../specs/area-pages.md)). 지역과 관계없는 후기라면 홈이나 서비스 페이지에 둔다.
- 이름 말고도 사는 동네, 병명, 사진처럼 본인을 알아볼 수 있는 단서가 있는지 본다.
