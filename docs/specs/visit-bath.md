# 방문목욕 페이지

`/services/visit-bath`가 근거로 삼는 운영 사실과 사진 규칙.

## 센터가 확인한 운영 방식

2026-10-06 센터 회신. 페이지 문구는 이 표 밖의 내용을 추측으로 쓰지 않는다.

| 항목            | 내용                                                                                                |
| --------------- | --------------------------------------------------------------------------------------------------- |
| 목욕 장소       | 목욕차 안 욕조. 댁 화장실에서도 할 수는 있지만 손해가 나서 하지 않는다.                             |
| 인원·시간       | 요양보호사 2명이 목욕을 하고, 기사님은 운전만 한다. 1시간.                                          |
| 차량까지 이동   | 부축하거나 업거나 휠체어로 모신다(2026-10-01 사진). 차 안 욕조는 리모컨으로 기울어져 들어가기 쉽다. |
| 받지 않는 경우  | 차량까지 모실 수 없는 어르신. 가장 필요한 분들이지만 댁 목욕은 손해라 하지 않는다.                  |
| 방문목욕만 신청 | 된다. 등급을 받고도 요양보호사가 오는 걸 불편해해서 목욕만 하는 어르신이 많다.                      |
| 운행 지역       | 경주·포항·안강. 영천은 이용자가 없어 기름값·이동 효율이 맞지 않는다.                                |
| 목욕차          | 2대.                                                                                                |

"받지 않는 경우" 때문에 페이지는 이용 대상을 "부축이나 휠체어로 목욕차까지 이동하실 수 있는 어르신"으로 쓰고,
누워 계신 분도 이용할 수 있다고 쓰지 않는다.

## 쓰지 않는 표현

"타 센터 대비 2배", "지역 최다" 같은 비교 표현. 근거를 확인하지 못했다.

## 사진

- **원본은 어디에도 올리지 않는다.** 저장소는 공개이고 R2 버킷도 공개다.
- 게시본은 R2 `pages/visit-bath/`에 둔다. 사진 게시판을 거치지 않아 `photos` 행이 없으므로, 내릴 때는 R2에서 직접 지운다.
- 가리는 것: 어르신 얼굴, 직원이 아닌 사람의 얼굴, 아파트 동 번호, 다른 차의 번호판.
  센터 회신은 "어르신 얼굴은 블러"였고 직원 얼굴은 가리지 않았다. 센터 목욕차 번호판은 둔다.
- 블러 영역은 자동 감지 대신 사람이 정한다 — 자동 감지가 옆얼굴과 작은 얼굴을 놓치는 한계는
  [photo-blur.md](photo-blur.md) "이 불변식이 덮지 않는 것". 블러 세기와 압축은 `lib/photo-blur.ts`의
  `BLUR_SIGMA`·`MAX_DIMENSION`·`WEBP_QUALITY`에 맞추고, EXIF(촬영 위치 포함)는 남기지 않는다.
- 올린 뒤 결과 이미지를 눈으로 다시 보고 가린 곳이 빠졌는지 확인한다.
