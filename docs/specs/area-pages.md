# 지역 안내 페이지

`/area/gyeongju`, `/area/pohang`. 목록은 `lib/service-areas.ts`의 `SERVICE_AREAS` 하나이고,
페이지·헤더·푸터 링크·사이트맵이 모두 여기서 읽는다.

## 지역마다 실제로 다른 내용이 있을 때만 둔다

지역명만 바꾼 페이지는 네이버·구글 모두 저품질로 보고 사이트 평가를 깎을 수 있다.
지금 지역마다 다른 내용은 **관할 국민건강보험공단 지사(장기요양 등급 신청 창구)**다.
센터는 읍·면·동을 가리지 않고 시 전역을 받는다고 답해서(아래 "센터 회신"), 방문 범위는 지역 간 차이가 되지 못한다.
지역 어르신 사례가 오면 그것이 차이가 될 수 있다 —
[`TODO_list/wait/testimonials.md`](../TODO_list/wait/testimonials.md).

## 센터 회신

2026-10-22 센터 회신. 페이지 문구는 이 표 밖의 내용을 추측으로 쓰지 않는다.

| 항목        | 내용                                                                                  |
| ----------- | ------------------------------------------------------------------------------------- |
| 방문 범위   | 경주시 전역, 포항시 전역. 그 지역에 요양보호사가 없으면 신청이 왔을 때 구해서 보낸다. |
| 요양보호사  | 안강 60명, 경주 1명, 포항 1명.                                                        |
| 이용 어르신 | 방문요양 80분, 방문목욕까지 합하면 150분.                                             |
| 영천        | 지금 이용자는 없지만 신청이 오면 간다.                                                |

- 인원은 센터가 "대략적으로" 적어 달라고 했다. `lib/service-areas.ts`의 `CAREGIVER_COUNT`·`CLIENT_COUNT`로
  어림한 값만 쓰고, 인사말과 지역 안내 페이지가 함께 읽는다.
- 지역별 인원(경주·포항 각 1명)은 싣지 않는다. 숫자가 작아 이용을 망설이게 할 수 있다.

## 만들지 않는 지역

- **안강** — 홈이 "안강 노인복지센터" 검색 1순위다(2026-09-15). 전용 페이지는 같은 검색어를 두고 홈과 겹친다.
  안강읍은 경주시라 공단 지사도 경주와 같아서, 따로 만들면 경주 페이지와 내용도 거의 같아진다.
  2026-10-24 헤더 "지역 안내"에 안강도 넣어 달라는 요청이 와서, 경주 페이지 안에 "센터가 있는 안강읍" 섹션
  (`#angang`)을 두고 헤더의 "안강"이 그리로 바로 간다(`CENTER_TOWN`). 섹션은 경주 페이지에만 있는 내용이 되고,
  경주 페이지 제목은 "경주 노인복지센터"라 홈과 겹치지 않는다. 지역별 요양보호사 수는 여기에도 싣지 않고
  "이용하시는 어르신도 안강에 많다"로만 쓴다.
- **영천** — 목욕차가 가지 않고([visit-bath.md](visit-bath.md)) 방문요양 이용자도 없다. 다만 신청이 오면 가므로
  사이트 곳곳의 "경주·안강·영천·포항" 표기와 `areaServed`는 그대로 둔다.

## 기대치와 측정

- 2026-09-15 네이버 검색에서 "경주 노인복지센터"·"포항 노인복지센터"는 사이트가 노출되지 않았다.
  네이버 플레이스 등록명은 `섬김노인복지센터`, 주소는 경주시 안강읍 화전중앙길 53이다.
- 플레이스(지도) 영역은 주소와의 거리를 반영하므로, 페이지를 만들어도 포항 검색의 플레이스 상단은 바뀌지 않는다.
  페이지가 노릴 곳은 웹사이트 영역이다.
- 네이버는 검색 데이터 API가 없어 순위는 검색 화면으로 보고, 유입은 GA4의 naver 소스로 본다.

## 링크

헤더의 "지역 안내" 칸, 푸터의 "서비스 지역", 방문목욕 페이지 본문이 링크한다. 안강 섹션은 헤더만 링크한다.
링크는 서버 HTML에 실려야 크롤러가 찾는다(`e2e/seo-links.spec.ts`).

2026-10-22 — 처음에는 헤더 칸을 늘리지 않고 푸터에만 두었는데, 푸터 링크만으로는 찾기 어려웠다.
"노인장기요양보험" 한 칸에 서비스와 제도 안내가 섞여 있던 헤더를 돌봄 서비스·장기요양보험·지역 안내로
나누면서 칸을 두었다.

## 공단 지사 정보

2026-10-22에 확인했다. 지사 페이지에 대표번호가 없고 직원별 내선뿐이라 전화는 공단 대표전화를 싣는다.
지사 정보를 고칠 때는 `NHIS_CHECKED_AT`도 함께 고친다.
